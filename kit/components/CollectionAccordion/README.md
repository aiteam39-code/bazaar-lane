# CollectionAccordion

Category or collection panels in a row; the one under the pointer (or keyboard focus) opens wide and shows its title, line and link.

**You provide** `items` (`title`, `image`, optional `subtitle`, `href`, `cta`) and optionally `height`.

- Mouse: hover opens. Touch: the first tap opens, the second follows the link. Keyboard: focus opens.
- Closed panels show their title vertically; under 480px of width the row stacks into a vertical list.
- Text over photos is always white on a dark scrim (the one place the kit names a colour), so use photos with a quiet lower third.

Use 3–6 panels on the home page for top categories or edits ("Ceramics", "Gifting under ₹999"). Don't put it above the fold on mobile as the only navigation.
